# Chatbot-using-Ollama

Ollama is a open source library to create Gen Ai applications. 

Requirement:
1. Run the Streamlit App

Open a new terminal and run:

streamlit run app.py

The app will open in your browser automatically.



2. Ollama must be running before starting the Streamlit app.

Ensure the required model is downloaded using ollama pull.

If you see connection errors, check that Ollama is running on localhost:1143
